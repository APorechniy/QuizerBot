# Бот для приема заявок через Quiz-механзим в ТГ

## Структура .env файла

Для корректной работы бота необходимо добавить токен.

.env
```
BOT_TOKEN=1234567890:ABCdefGhIJKlmNoPQRsTUVwxyZ_12345678
```

## Структура JSON-файла с вопросами

Структура файла достаточно простая. В `questions.json` хранится массив с вопросами.
Каждый вопрос имеет следующую структуру:

```
{
    "id": number,
    "text": string,
    "options": string[]
}
```

## Запуск

### Локальный запуск

Для запуска локально достаточно просто установить зависимости из файла `requirements.txt` и добавить файл `.env`.

- Установка зависимостей:
    ```
    pip install -r requirements.txt
    ```

- Запуск:
    ```
    python bot.py
    ```

### Запуск на сервере

Для запуска на сервере необходимо установить на него Docker и плагин Compose. Как это сделать - читай инструкцию своего хостинг провайдера.

- Клонируем репозиторий в папку на сервере
- Создаем `.env` файл
- При необходимости меняем список вопросов
- Запускаем командой
    ```
    docker compose up -d --build
    ```

Бот начнет работу.
